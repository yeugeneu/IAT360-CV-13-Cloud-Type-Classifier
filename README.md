# Cloud Type Classifier ☁️
A deep learning-based computer vision project for multi-label cloud classification and short-term weather prediction (now-casting). Developed by CV Group 13.

## 📋 Project Overview
Accurate cloud classification plays a vital role in short-term weather forecasting, climate studies, and outdoor event planning. This project implements a supervised deep learning model capable of classifying various cloud types—and supporting multi-label classification when multiple cloud formations appear simultaneously.

## Key Use Cases
Short-Term Weather Prediction (Now-casting): Predicting immediate weather conditions and upcoming changes.

## Possible extension:
* Climate Research: Studying how cloud formations impact Earth's temperature and climate patterns.
* Safety & Operations: Assisting with storm tracking and weather-dependent activities.

## ☁️ Target Cloud Types & Dataset
The project utilizes the Cloud Classification Dataset featuring categories such as:

1. Clear sky
2. Patterned clouds
3. Thick dark clouds
4. Thin white clouds
5. Thick white clouds
6. Veil clouds.
